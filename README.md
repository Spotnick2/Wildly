# Wildly

**Wildly** is a lightweight buff management addon for Druids in *World of Warcraft: TBC Anniversary*, inspired by PallyPower.

It focuses on persistent buff upkeep with minimal UI noise:

- Mark of the Wild / Gift of the Wild
- Thorns (mode-based targeting)

Wildly only runs for Druids.

---

## Features

- Compact group/raid buff tracker
- Secure click-cast row and popup workflow
- Group-cast + single-target fallback for Mark/Gift
- Thorns tracking modes:
  - Default (tanks in groups, self while solo)
  - Tanks only
  - Self only
  - Everyone
  - Disabled
- Gift reagent awareness by rank (Wild Berries / Wild Thornroot / Wild Quillvine)
- In-game configuration panel and slash command support

---

## Usage

Use:

```text
/wildly help
```

Open settings with:

```text
/wildly config
```

---

## Installation

### CurseForge

Install with the CurseForge client and enable in-game.

### Manual

1. Download a release zip.
2. Extract to:

   ```text
   World of Warcraft/_anniversary_/Interface/AddOns/
   ```
3. Ensure folder is:

   ```text
   AddOns/Wildly/
   ```
